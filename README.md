# Cloud Odyssey — Vercel Production Lab

Static, dependency-free browser app for Senior ML / AI Data Engineer production practice, focused on Hilton Grand Vacations scenarios.

## Production capabilities

- 10 worlds / projects
- 30 hands-on labs
- first try -> targeted feedback -> reveal -> unlimited retry
- code-pattern validator with reference solutions
- production incident diagnosis and root-cause reveal
- XP, levels, mastery, streaks and relics
- 60-item PROJECTS* deliverables checklist
- local persistence via localStorage
- production incident simulator
- responsive layout and keyboard Escape support
- Vercel headers and SPA rewrite config

## Deploy to Vercel

Suggested project name: `ktone-cloud-odyssey`

No environment variables are required for this version.
